One line, in the elevator's own voice — the funniest thing it would say if it could talk. It carries the same strangers every day and knows far more about them than they realise, yet every ride starts the same polite way.

## The entry

> I know which floor you cry on, and I still say "going up?" like we have never met.

82 characters — inside the 120-character limit.

## Run it

```sh
node main.ts
```

The program writes the line to `/output/entry.txt` (and prints it).
